#KnowledgeHub Monitor

Simple monitoring application for the KnowledgeHub Case.

## Current version

This first version stores configuration in memory.

The user can enter:

- hostname
- IP Address
- Metrics to monitor


##Example

Input:

Hostname: DC01
IP Address: 10.10.20.10
Metrics: cpu,memory,disk

Output:

---Monitoring Configuration ---
Hostname: DC01
IP: 10.10.20.10
Metrics:

- cpu
- memory
-disk
